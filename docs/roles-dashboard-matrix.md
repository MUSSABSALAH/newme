# الأدوار: ما يراه كل دور في لوحة التحكم

> ملف مولَّد من الكود وقاعدة البيانات — لا يُحرَّر يدويًا.
> المصدر: `App\Modules\Dashboard\Enums\DashboardPanel` + الأذونات المسنَدة فعليًا للأدوار.

لوحة التحكم لا تُبنى حسب اسم الدور، بل حسب أذوناته. كل لوحة (panel) مربوطة بأذونات الوحدة
نفسها التي تحمي صفحاتها، فمن يملك دورين تندمج لوحاته تلقائيًا، ومن لا يملك أي إذن وحدة يرى
بطاقة تشرح ذلك بدل صفحة فارغة.

## شروط ظهور كل لوحة

| اللوحة | يكفي امتلاك أحد هذه الأذونات | ما تعرضه |
| --- | --- | --- |
| **الشحنات** | `delivery.view` | شحنات اليوم (طلبات المتجر + تسليمات الاشتراكات)، المتبقي والمكتمل |
| **المالية** | `invoices.view`، `payments.view` | مبيعات اليوم والشهر، متوسط الفاتورة، عدد فواتير الشهر، أحدث ٥ فواتير |
| **الطلبات** | `orders.view` | طلبات اليوم والشهر والمعلّقة، توزيع الطلبات على الحالات، أحدث ٥ طلبات |
| **الاشتراكات** | `subscriptions.view`، `plans.view` | اشتراكات نشطة وموقوفة وجديدة هذا الشهر، ما يحتاج معالجة، توزيع الحالات، أحدث ٥ اشتراكات |
| **الاستشارات** | `consultations.view` | بانتظار التأكيد، استشارات اليوم، خلال سبعة أيام، توزيع الحالات، أقرب ٥ مواعيد |
| **كتالوج المتجر** | `catalog.view`، `inventory.view` | إجمالي المنتجات والمنشور والمخفي والمميّز، عدد المنتجات لكل تصنيف |
| **العملاء** | `customers.view` | إجمالي العملاء، الجدد اليوم وهذا الشهر، أحدث ٥ عملاء |
| **المحتوى** | `cms.view` | عدد المقالات والوصفات، وكم منها منشور |

ملاحظة: `reports.view` مستبعد عمدًا من لوحة المالية، لأن أدوارًا مثل مدير المتجر تحمله لأجل
أرقام قسمها، والإيرادات ليست من شأنها.

## كيف تُغيَّر هذه الجداول

- **صلاحيات دور:** من لوحة الإدارة › الأدوار. التعديل اليدوي يبقى محفوظًا؛ الـ seeder
  يكتب الافتراضيات فقط للأدوار التي لا تملك أي إذن.
- **الافتراضيات:** `app/Modules/Identity/Seeders/RolesAndPermissionsSeeder.php`.
- **ربط لوحة بإذن:** `app/Modules/Dashboard/Enums/DashboardPanel.php`.
- **محتوى لوحة:** `resources/views/admin/dashboard/*.blade.php` وأرقامها في
  `app/Modules/Dashboard/Services/DashboardService.php`.
